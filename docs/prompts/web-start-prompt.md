# Web Start

Desktop: type `/god`, select the corresponding skill, then add the task below.
For usage questions, choose `$godmode-help`; a clear task starts immediately.

```text
Use $godmode-workflow with $web-platforms.
Goal: <React, Next.js, or Node.js outcome>.
Done when: <observable behavior and focused project checks>.
Constraints: <runtime, browser, API, or compatibility boundaries>.
```
