# Review Start

Desktop: type `/god`, select the corresponding skill, then add the task below.
For usage questions, choose `$godmode-help`; a clear task starts immediately.

```text
Use $godmode-review. Keep the run read-only.
Target and base: <files, branch, PR, or release surface>.
Focus: <correctness, regression, security, contract, or release risk>.
Done when: findings are evidence-backed and ordered by severity.
```
